How to read the animation

Count dots crossing the plant boundary, rather than the number currently visible on a path. The streams begin in steady flow, with dots already in transit. More dots crossing each second represent a higher illustrative rate.

Each dot completes its path in one animation second. A one-second step updates the totals without continuous motion; the dots finish in the same positions after that complete cycle.

Input and output are separate gas exchanges. A CO₂ dot does not turn directly into an O₂ dot. Photosynthetic oxygen is formed from water; this diagram does not show the reaction mechanism.

The equal input/output counts use a simplified 1:1 gas-exchange model. Real rates depend on the plant and its conditions. Molecule controls change only the display, not the experiment.
